# AutoDig — автокопание области (Fabric 1.19.4)

## Управление (меняется в Настройки → Управление → AutoDig)
| Клавиша | Действие |
|---|---|
| **V** | Точка 1 — блок, на который смотришь (до 64 блоков) |
| **B** | Точка 2 |
| **Shift + V/B** | Сбросить выделение |
| **N** | Начать копание / остановить |

Область подсвечивается жёлтой рамкой. Копание идёт **слоями сверху вниз, змейкой,
от угла, ближайшего к тебе**, до конца области. Блоки ломаются «от твоего имени»:
используется инструмент в руке (зачарования, прочность, удача, шёлк), без нужного
инструмента блок ломается без дропа, как в ванилле. Дроп и опыт сразу в инвентарь.
Если инструмент почти сломан — копание останавливается.
Бедрок, вода и лава пропускаются.

## Команды
```
/autodig pos1 [x y z]     /autodig pos2 [x y z]
/autodig start            /autodig stop
/autodig speed <1-64>     блоков за тик (по умолчанию 2 = 40 блоков/сек)
/autodig pickup <true|false>
```

## Сборка
Нужна Java 17+ (https://adoptium.net). В папке проекта:
- Windows: `gradlew.bat build`
- Linux/macOS: `./gradlew build`

Готовый мод: `build/libs/autodig-1.19.4-1.0.0.jar` → положить в `.minecraft/mods`
вместе с Fabric API для 1.19.4.

На сервере мод тоже должен стоять (в одиночной игре — работает сам).
