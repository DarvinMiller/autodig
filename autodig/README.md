# AutoDig — автокопание области (Fabric 1.19.4, только клиент)

Мод ставится **только себе** в `.minecraft/mods` вместе с Fabric API.
На сервер ничего ставить не нужно: копает сам твой персонаж, как будто ты
зажал ЛКМ и ходишь по области.

## Управление (меняется в Настройки → Управление → AutoDig)
| Клавиша | Действие |
|---|---|
| **V** | Точка 1 — блок, на который смотришь (до 64 блоков) |
| **B** | Точка 2 |
| **Shift + V/B** | Сбросить выделение |
| **N** | Начать копание / остановить |

## Как копает
- Слоями сверху вниз; в каждом слое сначала ближайшие к тебе блоки, то есть
  копание начинается оттуда, где ты стоишь.
- Сам поворачивает голову к блоку и ломает его с обычной скоростью и дальностью 4.5.
- Когда рядом ничего не осталось, идёт к следующему блоку и перепрыгивает ступеньки.
- Сам берёт из хотбара лучший инструмент; почти сломанные инструменты не трогает.
- Пропускает бедрок, воду, лаву и блоки рядом с лавой.
- Ставится на паузу, пока открыт инвентарь или меню.
- Останавливается при здоровье 3 сердца и меньше, при смерти и по клавише N.
- Красной рамкой подсвечивается блок, который сейчас ломается.

На серверах с анти-читом автоматические действия могут считаться нарушением.

## Сборка
Нужна Java 17+. В папке проекта: `gradlew.bat build` (Windows) или `./gradlew build`.
Готовый мод: `build/libs/autodig-1.19.4-1.0.0.jar`.
